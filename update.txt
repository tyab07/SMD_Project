ENHANCED USABILITY FEATURES (BONUS)
===============================================================================

1. SAVE NEWS TO BOOKMARKS: Long-press any news article to save it directly
   into SQLite bookmarks under the "Saved News" folder. This bridges the
   API module with the Database module.

2. SHARE FUNCTIONALITY: Both news articles and bookmarks can be shared via
   Android's share Intent (WhatsApp, email, etc.).

3. FOLDER MANAGEMENT: Create new bookmark folders through an inline dialog
   in the add/edit bookmark screen.

4. SWIPE-TO-DELETE WITH UNDO: Swipe left on any bookmark to delete it.
   A Snackbar appears with an "UNDO" action to restore it.

5. EMPTY STATE VIEWS: Friendly empty-state messages with icons are shown
   when no bookmarks or news exist.

6. CONFIRMATION DIALOGS: AlertDialog appears before deleting bookmarks
   to prevent accidental data loss.

7. PULL-TO-REFRESH: SwipeRefreshLayout on the News tab allows users
   to refresh API data by pulling down.

===============================================================================
BACKGROUND THREADING
===============================================================================

All network calls and database operations use Kotlin Coroutines:
- Network calls: lifecycleScope.launch { withContext(Dispatchers.IO) { ... } }
- Database CRUD: lifecycleScope.launch { withContext(Dispatchers.IO) { ... } }
- UI updates happen on the main thread after suspend functions complete.
This ensures the UI never freezes during data operations.

DATABASE SCHEMA
===============================================================================

Table: folders (Parent)
+-----------+---------+------------------+
| Column    | Type    | Constraint       |
+-----------+---------+------------------+
| _id       | INTEGER | PK AUTOINCREMENT |
| name      | TEXT    | NOT NULL UNIQUE  |
| created_at| TEXT    | NOT NULL         |
+-----------+---------+------------------+

Table: bookmarks (Child)
+-----------+---------+-------------------------------+
| Column    | Type    | Constraint                    |
+-----------+---------+-------------------------------+
| _id       | INTEGER | PK AUTOINCREMENT              |
| title     | TEXT    | NOT NULL                      |
| url       | TEXT    | NOT NULL                      |
| note      | TEXT    | DEFAULT ''                    |
| folder_id | INTEGER | FK → folders(_id) ON DELETE CASCADE |
| created_at| TEXT    | NOT NULL                      |
+-----------+---------+-------------------------------+
